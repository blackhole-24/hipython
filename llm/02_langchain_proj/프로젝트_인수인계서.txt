1. 프로젝트 개요
================================================================

Streamlit 기반 웹 서비스로, 사용자가 회사명을 입력하면
MeiliSearch로 NASDAQ 종목을 검색하고, yfinance로 실시간
재무데이터를 수집한 뒤, GPT-4o-mini로 한글 투자보고서를
자동 생성하는 서비스.

실행 URL: http://localhost:8501
MeiliSearch 서버: http://localhost:7700

6. 파일별 역할 및 핵심 코드 요약
================================================================

[.env]
  역할: 모든 API 인증의 출발점. 없으면 서비스 전체 불가.
  내용: OPENAI_API_KEY, MEILI_SEARCH_KEY

[nasdaq_screener_1775713077275.csv]
  역할: MeiliSearch에 적재할 NASDAQ 종목 원본 데이터
  내용: Symbol, Name, Sector, Industry 등 11개 컬럼 × 7,082행
  주의: 파일명 뒷번호가 정확해야 함 (01_search_engine_setting.ipynb에서 경로 지정)

[01_search_engine_setting.ipynb]
  역할: NASDAQ 7,082종목을 MeiliSearch에 1회 적재. 검색 기반 구축.
  핵심 코드:
    - load_dotenv() → MEILI_SEARCH_KEY 로드
    - meilisearch.Client('http://localhost:7700', MEILI_SEARCH_KEY)
    - pd.read_csv(절대경로, na_filter=False)
    - client.index('nasdaq').add_documents(d, primary_key='id')
  주의사항:
    - MeiliSearch 서버가 켜진 상태에서 실행해야 함
    - add_documents는 비동기 처리 → 완료까지 20-30초 대기 필요
    - CSV 경로는 절대경로 사용:
      r'C:\Users\Admin\hipython\llm\02_langchain_proj\nasdaq_screener_1775713077275.csv'

[02_finance_data_yahoo.ipynb]
  역할: yfinance 동작 확인용 (서비스에 직접 연결 안 됨)
  핵심 코드: yf.Ticker('MSFT').history(), financials 등 테스트

[03_user_prompt.ipynb]
  역할: LangChain LCEL 파이프라인 단독 테스트. investment_report.py의 프로토타입.
  핵심 코드:
    - from stock_info.stock_info import Stock  ← 반드시 이 경로 사용
    - chain = prompt | llm | output_parser
    - chain.invoke({company, basic_info, financial_statement})

[search/stock_search.py]
  역할: 사용자 입력 텍스트 → MeiliSearch 검색 → 종목 hits 반환
  핵심 코드:
    from dotenv import load_dotenv
    import os
    load_dotenv()
    MEILI_SEARCH_KEY = os.environ['MEILI_SEARCH_KEY']
    import meilisearch
    client = meilisearch.Client('http://127.0.0.1:7700', MEILI_SEARCH_KEY)
    def stock_search(query):
        return client.index('nasdaq').search(query)

[stock_info/stock_info.py]
  역할: 티커 심볼 → yfinance 실시간 재무데이터 수집 및 마크다운 변환
  핵심 코드:
    class Stock:
        def __init__(self, symbol):
            self.ticker = yf.Ticker(symbol)
        def get_basic_info() → longName, industry, sector, marketCap, sharesOutstanding
        def get_financial_statement() → 손익계산서 + 대차대조표 + 현금흐름표 (마크다운)
  주의: reindex() 사용으로 KeyError 방지

[report_service/investment_report.py]
  역할: 기본정보 + 재무제표 → GPT-4o-mini → 한글 투자보고서 생성
  핵심 코드:
    llm = ChatOpenAI(model='gpt-4o-mini')
    prompt = ChatPromptTemplate.from_messages([system, user])
    chain = prompt | llm | StrOutputParser()
    chain.invoke({company, business_info, financial_statements})

[app.py]
  역할: 전체 서비스의 진입점. UI 구성 및 3개 모듈 통합.
  핵심 코드:
    from search.stock_search import stock_search
    from stock_info.stock_info import Stock as StockInfo
    from report_service.investment_report import investment_report
    st.text_input() → stock_search() → st.selectbox()
    → StockInfo().get_basic_info() / get_financial_statement()
    → investment_report() → st.write()

[health_check.py]
  역할: 개발/디버깅용 환경 점검 스크립트 (서비스 운영과 무관)
  점검 항목: Python 버전, 라이브러리 설치, API 키, yfinance, MeiliSearch, Stock 클래스, investment_report import

11. 주요 오류 및 해결 이력
================================================================

오류 1: KeyError: 'MIELIE_SEARCH_KEY'
  원인: .env의 키 이름(MEILI_SEARCH_KEY)과 코드의 변수명 불일치 (오타)
  해결: 모든 파일에서 MEILI_SEARCH_KEY로 통일

오류 2: ImportError: cannot import name 'Stock' from 'stock_info'
  원인: stock_info가 폴더(패키지)인데 from stock_info import Stock 사용
  해결: from stock_info.stock_info import Stock

오류 3: SyntaxError: 'return' outside function
  원인: investment_report.py에서 함수 본문 들여쓰기 누락
  해결: output_parser, chain, response, return을 4칸 들여쓰기

오류 4: FileNotFoundError: nasdaq_screener_***.csv
  원인: 상대경로 + 파일명 불일치
  해결: 절대경로 사용 + 실제 파일명(1775713077275) 확인

오류 5: index_not_found (nasdaq)
  원인: add_documents 비동기 처리 완료 전 검색 시도
  해결: add_documents 실행 후 30초 대기, 또는 01_search_engine_setting.ipynb 재실행
